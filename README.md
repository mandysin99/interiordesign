## 四套GLB

1. `VB-01_01_建筑保留基准_未封窗.glb`：建筑、交付保留精装与原入户柜；无新定制、活动家具、新封窗。保留客厅阳台原推拉门。
2. `VB-01_02_建筑保留基准_已封窗.glb`：同一建筑保留基准，加独立新封窗组，移除原客厅阳台推拉门。除封窗外采用交付精装基准。
3. `VB-01_03_定制家具参考_未封窗.glb`：当前硬装、定制与家具参考，同时保留原推拉门。未封窗不再绑定“未装修”。
4. `VB-01_04_定制家具参考_已封窗.glb`：当前方案，显示新封窗，移除原推拉门。

四套是可替换的完整场景，**不要叠加导入**，否则建筑会重复。

## Blender接入

GLB单位米，glTF为Y-up；使用Blender标准glTF导入器转换坐标，勿再次手动缩放100或1000倍。主卧床垫宽1.8m、小次卧1.5m，冰箱800×657×1930mm，可作导入尺度检查。节点名和semantic_layer额外属性保留，分组为空物体层级，未保证自动变成Blender Collection。

01建筑、02保留精装、03定制、04家具、05新硬装、06封窗均可独立识别。预览顶板、中央天花、边吊风口单独命名，室内作图可在Blender隐藏；隐藏不代表现场没有吊顶。门关闭，书房床收起、梳妆台收起；GLB不含网页交互、动画或灯光相机。拆改线框、水电示意和检查包络不导出。

## 用户接受的方案条件

- 主卧柜体部分遮挡回风，保留柜体；其余有效回风面积由空调师傅现场确认。不是必须取消柜体的硬冲突。
- 儿童房接受柜内检修，上方为可拆卸顶板；节点标记removable。拆卸路径和五金细节现场深化。不是必须取消柜体的硬冲突。

## 已知限制

书房完成面仍差约36mm、过道约17mm；厨房局部完成面2120×2040mm已更新，但全屋统一定位未通过。多数吊顶和楼板高度仍为预览；2.95m不是实测层高。入户最新全景仅用于柜门分格、开放格和灯带关系核对，柜体总高、收口、鞋位净空、门把手、插座和回风检修仍待量尺确认。书房展开床与固定书柜冲突仍在，本版以收起状态交接。冰箱安装间隙、窗框分格、隐藏水电走线未确认。纹理和家具是视觉概括，不是厂家模型；不新增软装细节。
